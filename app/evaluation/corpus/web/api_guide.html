KnowledgeHub-AI API Documentation

Version 2.4 - Enterprise Retrieval & Ingestion Service

1. Overview

The KnowledgeHub-AI API provides programmatic access to document ingestion, hybrid vector retrieval, and provenance tracking across enterprise knowledge stores.

2. Authentication

All API endpoints require authentication via an API Key. Include your key in the HTTP request header as follows:

Authorization: Bearer kh_live_99824_prod_key

Unauthenticated requests will return a 401 Unauthorized response. API keys must be kept secure and never exposed in client-side applications.

3. Rate Limits & Quotas

Standard enterprise tier accounts are limited to 1,200 requests per minute per organization ID. Burst capacity allows up to 50 concurrent ingestion calls before returning 429 Too Many Requests.

4. Document Ingestion

Submit multi-format documents (PDF, DOCX, XLSX, PPTX, HTML) to the ingestion pipeline using the POST /v1/ingest endpoint.

Supported payload formats include multipart form-data for file uploads and JSON payloads for structured metadata registration.

5. Retrieval & Provenance Query

To retrieve chunks with metadata attribution, send a POST /v1/query request containing the query string, top_k parameters, and optional content-type filters.
